# Fresh Feed 
A news reader I built as part of my college project.
Pulls live news from RSS feeds.

## Built With
- HTML — page structure
- CSS — styling and responsive layout
- JavaScript — fetching and rendering news
  
## Sources
BBC News,The Kathmandu Post

## What it does
- News from Nepal, Asia and around the world
- sports updates
- health news updates
- Trending🔥 contents updates
- Live weather for Pokhara
- Search across all articles

## How to run
1. Clone the repo
 https://n-kaushal123.github.io/FRESH-FEED/
2. Open in VS Code with Live Server extension
